## 三合一是什么意思

- 2026-10-12 起，Grok 会员和 X 会员合并，一个会员同时包含 Grok（聊天、生图、视频、语音）、Cursor（写代码工具）和 X（推特）会员；新用户只能买三合一，不能再单独买 SuperGrok。

- 官方新出的"Super"是更高的一档，**不是**原来的 SuperGrok；原 SuperGrok 对应的是 Premium。

## 封号风险与申诉

先说清楚：代充不是官方渠道，账号被封的诱因大多在使用这一侧，不在付款这一侧。常见诱因：

- 在 xAI / X 不支持的地区使用，或频繁切换网络所在国家。
- 多人共用一个账号、多地同时登录。
- 用脚本批量调用，或在 X 上有违规行为（X 账号被限会连带影响三合一会员）。
- 注册时用了虚拟号码、一次性邮箱。

降低风险的习惯：网络环境保持稳定、一个账号只给自己用、不要用脚本刷、X 账号正常使用。

被封了怎么办：先看注册邮箱里的通知，按 xAI 或 X 的官方帮助页提交申诉；能否恢复、订阅费是否退，以官方处理结果为准。封号不在本店质保范围、不退款。
