## 三合一是什么意思

- 现在 Grok 会员和 X 会员合成一个订阅（定价页标题"One subscription. Access to everything."），付费档同时包含 Grok（聊天、语音、生图视频等）、Cursor 和 X 会员权益。

## 方法一：官方网页订阅

- **怎么做：** 在 grok.com 或 x.ai 登录 → 选择套餐 → 付款。
- **价格：** 按上表官方美元价，另加当地税费。
- **条件：** 定价页 FAQ 写明自助订阅"支持所有主流信用卡和借记卡"（2026-10-26 核对）。没有支付宝、微信。
- **优点：** 官方唯一明确授权的渠道；可以随时取消。
- **缺点：** 国内发行的卡经常付不了。
- **风险：** 付款风险最低；账号风险看使用地区和使用习惯。

## 方法二：苹果 / 谷歌应用内购

- **现状：** xAI 官网列出了 Grok 的 iOS 和安卓 App，但定价页 FAQ 建议"只通过官网购买"。App 内能否订阅、价格多少，**本次没有核对**，以你所在地区 App 内显示为准。
- **一般规则：** 应用内购的订阅由苹果 / 谷歌管理，取消、退款要在应用商店里办；Apple 礼品卡余额可以买订阅，但不是所有国家或地区都有礼品卡（[Apple 官方](https://support.apple.com/en-us/118242)，2026-10-26 核对）。
- **风险：** 要有外区商店账号；网页和 App 各订一份会重复扣费。

## 方法三：礼品卡

- 官方定价页没有列出 Grok 礼品卡产品（2026-10-26 核对），并且官方不授权任何第三方卖家。
- 网上卖的"Grok 礼品卡""Grok 兑换码"，请先问清到底是什么，按官方说法都属于未授权来源。

## 方法四：代充（第三方代付）

- **是什么：** 第三方卖家替你付款，把 Premium 开到**你自己的账号**上。
- **价格：** 卖家自己定价。
- **条件：** 每家不同，下单前看清商品页写的账号条件。
- **优点：** 支付宝 / 微信就能付；不绑你的卡、不会自动续费。
- **缺点：** 非官方渠道，不能找 xAI 退款。
- **风险：** xAI 明确写明不授权第三方，从其他来源买的订阅账号可能被暂停或终止（见上面"官方立场"）；另外还有卖家不靠谱、索要密码导致账号被盗等一般风险。

怎么挑卖家：价格正常、不要密码、到账时间说得清、失败怎么退、掉订阅管不管、售后找得到人。逐项说明见主仓库 [gpt-chongzhi](https://github.com/haiwaihuyonghui-rgb/gpt-chongzhi#怎么判断代充靠不靠谱6-个判断点)。不建议合租 / 拼车：额度按账号算，多人共用容易触发风控。

## 买哪一档

- **Free**：偶尔用一下。
- **Plus**：官方推荐给 AI 用量少、主要用 X 的创作者。
- **Premium**：官方推荐给新的 AI 用户；每天用 Grok 聊天、生图、生成视频的买这一档。
- **Super / Ultra**：官方推荐给每天用智能体的人和重度用户。

## 封号风险

常见诱因：在不支持的地区使用或频繁切换网络所在国家；多人共用、多地同时登录；用脚本批量调用；X 账号违规（三合一会员会连带受影响）；以及上面官方说明的"从未授权来源购买"。被封后先看注册邮箱里的通知，按 xAI 或 X 官方帮助页申诉，结果以官方为准。

## 常见问题

**Q：Grok Premium 官方多少钱？**
A：30 美元/月，不含税（x.ai/pricing，2026-10-26 核对）。

**Q：Premium 和 Super 是一回事吗？**
A：不是。Premium 对应原来的 SuperGrok；Super 是更高一档，100 美元/月。

**Q：官方允许代充吗？**
A：不允许。xAI 定价页写明不授权任何经销商或第三方卖家，从其他来源买的订阅可能被暂停或终止。

**Q：买了 Premium，X 会员和 Cursor 怎么用？**
A：付费档同时包含这三样，Grok 和 Cursor 共用每周刷新的用量池；具体关联方式按官方页面提示操作。

**Q：会自动续费吗？**
A：官网订阅会自动续费，要在续费前至少 24 小时取消；代充不绑你的卡，不会自动续费。
